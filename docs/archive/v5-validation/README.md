# Original V5 validation and generated previews

These files preserve the September 26 original pack evidence, logs and generated prompt previews. Its reported 513 passing checks comprise 189 Python, 107 Node and 217 schema cases. They were not rerun here and do not validate the combined application.

Preview JSON hashes refer to the original pack's invariant/registry paths. Relocating current registry owners changes those digests, so these previews are explicitly historical and not current runtime assemblies. Active prompt consumers remain unchanged.
