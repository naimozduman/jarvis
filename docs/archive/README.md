The files under v3/ are unmodified source-era research contracts and ADR snapshots from the supplied overlay. Their original labels, including “accepted”, are claims made by that overlay. V4 does not treat them as evidence of repository acceptance.

Do not copy this directory into the active ADR or schema directories. During J4-M00, compare against the real repository. Existing accepted ADRs and migrations remain authoritative until an independently authorized change supersedes them. The reference snapshots are exempt from V4 frontmatter rules so their source bytes remain intact.
