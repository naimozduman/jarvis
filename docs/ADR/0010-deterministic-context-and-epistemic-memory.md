# ADR 0010 — Deterministic context retrieval and epistemic memory promotion

## Status

Accepted

## Context

Early vector retrieval would obscure why sensitive records were supplied, while a model deciding its own memory truth would allow hallucinated or emotional state to become durable.

## Decision

Phase 2 uses owner-scoped structured retrieval and deterministic ranking with persisted manifests. Memory candidates preserve authority and evidence. Model inference remains a hypothesis; observations remain observations; preferences need repeated evidence or owner review; and active constitutional values cannot be rewritten from behavioral data.

## Consequences

Retrieval is explainable and redaction-aware now, with an interface that can add vector retrieval later. JARVIS trades broad fuzzy recall for auditable, safe, typed state during the first intelligence phase.
