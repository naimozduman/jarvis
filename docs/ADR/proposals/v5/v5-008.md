## Proposal identity

Proposal: V5-008. Status: proposed, not accepted. Acceptance evidence: none. Repository number: unassigned. Owner: Naim. Base repository must be reconciled at J5-M00.

## Context

Daily Brain tuning must not depend on an unofficial messaging channel being available.

## Decision

Add Surface Zero with owner-authenticated text and read-only status before WhatsApp is a required surface. Full control center stays later.

## Alternatives considered

Moving the entire dashboard early delays useful work. Leaving WhatsApp as the only surface couples availability to transport review.

## Security and privacy impact

Surface Zero has no public registration and no high-impact writer.

## Consequences

This adds explicit review and test work at the affected boundary. It reduces ambiguous authority but does not eliminate operator error, malicious administrators, provider defects, or test blind spots. The owning design is [SURFACES_AND_CLIENTS.md](../../../design/SURFACES_AND_CLIENTS.md).

## Migration and compatibility

Gate on authentication, source-backed state and safe session recovery. Preserve current implementations until the relevant mission proves compatibility. A staged rollback must restore the previous accepted implementation without reviving expired authority.

## Acceptance evidence

Pending. Require exact base/head, test report, owner authorization and trusted gate result. Do not fill these with a fabricated success.

## Supersession

None activated. At promotion, identify any actual accepted ADR to supersede and assign a repository ADR number. This proposal does not supersede history by filename.
