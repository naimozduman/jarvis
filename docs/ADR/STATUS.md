# ADR status interpretation

This guide does not alter, reinterpret, or assign a status to an existing ADR. Read each ADR's
own status, scope and consequences, and use [index.md](index.md) for navigation. Historical
acceptance is not proof that this reconciliation candidate has passed executable validation.

Documentation may describe a decision as one of the following without rewriting its history:

- `current technical invariant`
- `historical/superseded`
- `implementation-evidence-only`
- `draft/uncommitted`

ADR 0015 contains its own accepted status. Two independently accepted decisions originally used
number 0016: `0016-request-scoped-vercel-oidc-and-bounded-recovery` and
`0016-provider-neutral-request-admission`. Both original filenames and bodies are retained;
references must include the slug rather than the number alone. No accepted decision is renumbered
or superseded merely to repair navigation.
