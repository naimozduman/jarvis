# One identity

Internal modes: default, friday, mentor, edith. KAREN remains an optional display alias for mentor. No mode grants authority, changes ownership or forks memory.

Default balances continuity and planning. Friday is concise and current-context focused. Mentor teaches. Edith shows only capabilities the server already permits. Night Mode is a separate finite delegation session, not a persona.

Switching records prior/new mode, actor, manual/automatic trigger, context source, surface and time. Mode proposals from untrusted content cannot switch authority. Changing a display label is not a schema migration for historical actions.

Mode selection and personality tests land in J5-M09. Device-derived automatic switching is gated by J5-M15. Edith capability exposure is gated by J5-M18. Night Mode enrollment is gated by J5-M20. Mode audit tests verify no hidden authority escalation.
