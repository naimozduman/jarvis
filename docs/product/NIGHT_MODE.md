# Preserve overnight help without permanent authority

Draft mode reads approved sources, organizes, prepares drafts and reports. Handoff mode covers only separately enrolled routine controlled-write cases. Full Handoff is an optional future UI label, not expanded blanket authority. All modes use the same policy.

External leases are finite, target/action/account allowlisted, use-limited, and end with the explicit sleep episode, at most the proposed 12-hour maximum. No HIGH_IMPACT action executes or gets approved through unattended Night Mode or a standing lease. Relationship/intimate messages remain draft-only in the baseline.

An owner consciously awake during a scheduled sleep window first ends/overrides the sleep session through a trusted first-party control and performs fresh step-up for any high-impact approval. No model-authored urgent email can perform either transition. No midnight-based restriction is inferred for Naim's night work.

## Admission and recovery

Before entry verify current policy, finite lease, owner-selected sleep window, source coverage, cost/interruption budgets and independent stop controls. Every mode transition and lease use is audited. Stale enrollment never auto-renews. Scope additions require a new preview and authorization.

## Morning handoff

Group what arrived, verified effects, drafts, things deliberately deferred, uncertain outcomes, failed jobs, source coverage and approvals still pending. Report zero completed work when none is evidenced. A missed brief does not erase outstanding obligations.

## Test gate

J5-M20 follows the approval, executor and worker gates. Test malicious urgency, expired overnight lease, stale sleep context, owner absence, service outage, cost exhaustion, voice interruption and revocation during dispatch. These tests are separate from a monthly design review.

## Detailed contract owner

[Messaging and Handoff](../integrations/MESSAGING_AND_HANDOFF.md) owns history coverage, normalized identity/edits/deletions, durable Handoff transitions, one-sender/takeover/expiry fencing, narrow disclosure, presence/media capability distinctions, calendar candidates and exact return-brief authorship/outcome tests. These compatible retained details do not authorize baseline relationship/intimate sending or HIGH_IMPACT work under unattended enrollment.
