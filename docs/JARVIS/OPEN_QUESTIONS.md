## How to close an item

Record the result, tested version/device/account mode, evidence and limits in the owning document and [DECISIONS.md](DECISIONS.md) where it changes a decision. Update the requirement ledger and roadmap gate. A successful demo in one app/account does not establish every network/firmware, and an unresolved technical test should not be reframed as a request for the owner to remember old conversations.
