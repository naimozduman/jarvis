## Reading and evidence conventions

Sources were inventoried, parsed into speaker/timestamp/message boundaries, and read in 58 continuous sections. Exact repeated long paragraphs could be referenced during extraction; unique content was not omitted. All original message text was retained in working artifacts. Pasted code, operational reports and short side conversations were covered, then classified rather than automatically promoted to requirements.

`S2-M0043` means the 43rd message in source S2, counting both Prompt/user and Response/assistant blocks from the beginning. Source line numbers in the ledger identify the original Markdown message heading. Dates below are displayed export timestamps with **no declared timezone**; no UTC conversion was invented. Branch creation and export times are not message chronology. The current direct request is cited as `CURRENT` and takes precedence over historical conversations.

A user-role message may contain a pasted assistant/Codex report. Reports are labeled as such. Assistant proposals require actual user adoption; repetition is not approval. Images, old PRDs, ZIPs, PDFs, DOCX files and repository links mentioned inside exports were not separately supplied as accessible source bytes and are not claimed as independently inspected. Source chat links may require the owner's account.
