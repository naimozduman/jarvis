## Evidence boundary

The uploaded Muse reports and transcript are the supplied research. Their VERIFIED labels record Muse's claims, not new verification performed during V5 packaging. This file retains source locators and separates candidate mechanisms from adoption. Dates, prices, star counts, model IDs and private wiring from those reports are not active configuration.

No external framework is selected or installed by this pack. See proposed V5-009 for the proposed adoption process. Architectural continuity follows the owner PRD and approved repository decisions. Research-derived ideas require an accepted decision and component-level tests before adoption.

## Corrections retained from the reviews

Hermes staging and memU memory tracks are separate findings. Arcus and OpenClaw are separate systems. A forwarded GitHub link is not proof a creator used that repository. Removing refusal behavior is not evidence of better agency or permission safety. Report arithmetic using total revenue does not by itself establish advertising attribution. “Local-first” must be checked for every audio, embedding, reasoning and storage hop.
