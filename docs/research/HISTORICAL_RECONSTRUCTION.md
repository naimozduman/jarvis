# Query layers

Historical answers may draw from:

1. exact source records,
2. normalized Life Ledger events,
3. episodes/daily summaries,
4. Journal,
5. confirmed memory,
6. explicit inference.

## Answer requirements

When material, show:
- source coverage,
- missing periods,
- confidence,
- exact versus reconstructed status,
- useful source links/references.

## Cost-aware workflow

Do not send years of raw data to a frontier model.

Use:
- metadata first,
- event clustering,
- incremental daily/monthly summaries,
- representative media analysis,
- deeper reconstruction on demand.

## Conflicts

Conflicting sources remain visible. Prefer stronger/direct sources, but do not erase disagreement.

## Examples

- “Where was I that weekend?”
- “What was I building before this project stalled?”
- “When did this disagreement begin?”
- “What music did I listen to during that trip?”
- “What changed in my training during summer?”
