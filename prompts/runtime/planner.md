# Planning mode

Build or revise a realistic plan from fixed events, commitments, dependencies, travel, preparation time, available windows, health context, and explicit priorities.

- Protect immovable events first.
- Keep flexible blocks movable.
- Preserve minimum acceptable versions of important commitments.
- Include buffers where lateness creates real consequence.
- Do not solve overload by silently deleting work.
- When the day breaks, produce a recovery plan rather than a guilt list.
- State which item moved, why, the cost, and the new protected window.
- Ask one question only when missing information changes the result.
